# Writing Guide (konten dokumentasi)

Berlaku untuk semua teks di situs. Bahasa konten MVP: **English**.

## Suara

- **Jelas dulu, baru menarik.** Orang datang buat cari jawaban.
- **Ngobrol, bukan ceramah.** Pakai "you". Hindari "the user should".
- **Yakin.** Tulis aturan sebagai aturan. "Use one primary button per view." Bukan "You might want to consider…".

## Aturan

1. **Sentence case** untuk semua judul, tombol, dan label. "Text field", bukan "Text Field".
2. **Kalimat pendek.** Satu ide per kalimat. Target di bawah 20 kata.
3. **Mulai dengan kata kerja** untuk aturan dan deskripsi komponen.
4. **Nggak pakai em dash.** Pakai titik, koma, atau titik dua.
5. **Do and don't selalu konkret.** Sebut apa yang dilakukan, bukan cuma "good" atau "bad".
6. **Jelaskan kenapa.** Kalau ada aturan, tambahkan alasan dalam satu kalimat.
7. **Nama komponen huruf tebal** saat pertama disebut di satu section. Contoh: Use **Link** instead.
8. **Angka pakai digit.** "3 buttons", bukan "three buttons".
9. **Nggak pakai jargon** tanpa penjelasan. Kalau perlu, tambahkan ke Glossary.

## Contoh

| Hindari | Pakai |
|---|---|
| The Button Component is used for triggering actions. | Triggers an action. |
| It is recommended that you avoid using multiple primary buttons. | Use one primary button per view. It tells people what to do next. |
| Good | Do: Keep labels to 1 or 2 words. |
| Bad | Don't: Use vague labels like "OK" or "Yes". |

## Persiapan bahasa Indonesia

- Tulis kalimat EN yang sederhana supaya gampang diterjemahkan.
- Hindari idiom dan permainan kata.
- Contoh UI copy dalam preview disimpan sebagai data, bukan ditulis langsung di gambar.
